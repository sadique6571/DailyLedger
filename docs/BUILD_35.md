# Build 35 — compact preview-inspired UI

Version remains 2.0.0. The header now uses compact branding with Search and AI Auto Fill at the corner. Time-aware greeting/name emojis and a small live weather chip replace the large decorative greeting card. Light/Aqua use a restrained teal palette; Dark uses readable navy surfaces. Selected bottom tabs have a tonal pill.

Existing LedgerCard shapes, gradients, borders and shadows are retained. Monthly totals use compact icon/value rows inside the same card treatment. The balance keeps its gradient, progress, daily spending guide, salary countdown, privacy and low-balance warning. Dashboard gaps are tighter. Existing money-space cards, history, frequent-purchase records and entry flows remain available.

AI insights stay at the end of the dashboard and retain their individual cards. “Not useful” buttons are removed from offline and online cards; existing saved feedback is respected. Online refresh stays manual. The reminder center previously opened by the header bell is available through More → Reminders.

UI-only update: no database, backup schedule, encryption, financial calculations, AI parsing/service or signing changes. Regression checks include header actions and Light/Dark screenshots, insight cards/manual refresh without dismiss buttons, and the reminder route, alongside the existing suite.
