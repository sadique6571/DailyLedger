# Build 36 — full preview layout and floating expense entry

Version 2.0.0, build 36. Completes the preview-inspired native layout beyond the header: greeting and weather share a row, the gradient balance is shorter, Salary and Expense are the main two summary tiles, other income remains actionable with the separate money sections, and content has bottom clearance for the floating action. Existing rounded card shapes, borders, shadows, amounts, daily guide, salary countdown, low-balance warning and privacy stay intact. AI insights remain at the end without dismissal buttons.

The floating plus button above bottom navigation opens expense entry on main screens. The existing transaction editor now opens from the bottom as a rounded modal sheet, including salary/income and editing. Fields scroll while Save/Cancel stay pinned above the keyboard. Amount presets replace the typed amount. Existing date/category validation, history/advanced options and discard confirmation are retained. Draft fields survive recreation. No storage, backup, encryption, AI parsing, calculation or signing changes.

Validation includes the existing transaction/category/date and Urdu accessibility checks, light/dark screenshots, plus floating-button-to-sheet save and unsaved-cancel tests.
